🎮 Tic Tac Toe
A web-based implementation of the classic Tic Tac Toe game, developed using HTML, CSS, and JavaScript. This project demonstrates core front-end development concepts including DOM manipulation, event handling, and game logic design through an interactive user interface.

🚀 Features:-
* Two-player gameplay (Player X vs Player O)
* Real-time win detection (rows, columns, diagonals)
* Draw detection when grid is full
* Game state control to prevent invalid moves
* Reset functionality for continuous gameplay
* Responsive and user-friendly interface

🛠️ Tech Stack:-
* **HTML** – Structure of the application
* **CSS** – Styling and layout design
* **JavaScript** – Game logic and interactivity

🎯 Project Objective:-
The primary goal of this project is to strengthen foundational JavaScript concepts by building a logic-driven application. It focuses on handling user interactions, managing game state, and implementing condition-based outcomes in a structured manner.

🧠 Key Concepts Implemented:-
* DOM manipulation
* Event listeners and user interaction handling
* Conditional logic and state management
* Dynamic UI updates without page reload
* Modular and readable code structure

📂 Project Structure:-
tic-tac-toe/

▶️ How to RUN:-
1. Clone the repository
2. Open `index.html` in any web browser
3. Start playing
